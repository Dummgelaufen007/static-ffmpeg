# Add librist

- librist: https://code.videolan.org/rist/librist

## Assessment

- FFmpeg 9.1: protocol `librist` (`librist_protocol_deps="librist"`).
- Use: RIST is the VSF's open standard for broadcast contribution over the internet, the counterpart to the already enabled `libsrt` (not checked against a source).
- Container relevance: high; stream contribution is a typical headless job.
- Future: growing.
- Open: static musl build not checked.
