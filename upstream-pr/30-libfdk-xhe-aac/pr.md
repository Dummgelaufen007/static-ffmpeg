# Add libfdk-xhe-aac

With `ENABLE_FDKAAC` set, ffmpeg also gets the `libfdk_xhe_aac` encoder for xHE-AAC, new in ffmpeg 9.1. fdk-aac 3.0.0 already builds and installs the fdk-xhe-aac library ([ChangeLog](https://github.com/mstorsjo/fdk-aac/blob/v3.0.0/ChangeLog#L2)).
